# OBS 가림 박스 오버레이

방송 화면에서만 닉네임을 덮는 오버레이입니다. 체스닷컴을 전혀 건드리지 않아서
확장 프로그램처럼 계정에 영향을 줄 걱정이 없고, **내 모니터에는 이름이 그대로 보입니다.**
시청자 화면에서만 사라집니다.

| 파일 | 역할 |
| --- | --- |
| `editor.html` | 스크린샷 위에 박스를 그려 프리셋을 만들고, OBS 에 넣을 주소를 뽑는 편집기 |
| `overlay.html` | OBS 브라우저 소스가 읽는 오버레이 본체 |

## 1. 박스 그리기

1. 체스닷컴 화면(게임 / 분석·리뷰 / 퍼즐 / 홈·친구창)을 각각 **캡처**해 둡니다.
2. `editor.html` 을 평소 쓰는 브라우저에서 엽니다.
3. 프리셋 탭을 고르고, 해당 화면의 캡처를 창에 **드래그**하거나 `Ctrl+V` 로 붙여넣습니다.
4. 가릴 자리를 마우스로 끌면 박스가 생깁니다. 박스를 끌면 이동, 오른쪽 아래 손잡이로 크기 조절,
   `Delete` 로 삭제입니다.
5. 오른쪽에서 라벨(`Player 1` 같은)과 색을 정할 수 있습니다. 라벨을 비우면 그냥 덮기만 합니다.

좌표는 화면 크기에 대한 **비율(%)** 로 저장되므로, 해상도나 소스 크기가 달라져도 자리가 맞습니다.
다만 브라우저 창 크기를 바꾸면 체스닷컴 레이아웃 자체가 달라지니, **방송할 때 쓰는 창 크기로
캡처**하고 그 크기를 유지하세요.

## 2. OBS 에 넣기

프리셋 하나당 브라우저 소스 하나를 만듭니다.

1. 편집기에서 `overlay.html` 경로를 적습니다. 예: `file:///C:/obs/overlay.html`
2. **현재 프리셋 주소 복사** 를 누릅니다.
3. OBS → 소스 `+` → **브라우저**
4. **로컬 파일 체크는 끈 채로**, URL 칸에 복사한 주소를 붙여넣습니다.
   (로컬 파일로 고르면 뒤에 붙은 설정값을 넣을 수 없습니다.)
5. 너비·높이를 방송 해상도와 같게 맞춥니다. 예: 1920 × 1080
6. 소스를 체스닷컴 캡처 **위쪽**에 둡니다.

프리셋 수만큼 3~5번을 반복하고, 소스 이름을 `가림-게임`, `가림-퍼즐` 처럼 붙여둡니다.

## 3. 화면 전환용 단축키

OBS → 설정 → **단축키** 에서 각 소스의 **표시 / 숨기기** 에 키를 지정합니다.
예를 들어 게임용 `F1`, 분석용 `F2`, 퍼즐용 `F3` 처럼 두면 화면을 옮길 때 키 하나로 바뀝니다.

한 번에 하나만 켜지게 하고 싶다면, 각 오버레이를 **장면(Scene)** 으로 나누고
장면 전환 단축키를 쓰는 편이 더 깔끔합니다.

## 설정 백업

편집 내용은 브라우저에 자동 저장됩니다. 다만 `file://` 로 연 페이지는 브라우저 설정에 따라
저장이 막힐 수 있으니, 공들여 잡았다면 **설정 JSON 복사** 로 따로 보관해 두세요.
다른 PC에서는 **설정 JSON 불러오기** 로 그대로 옮길 수 있습니다.

주소 안에 설정이 통째로 들어 있으므로, 박스를 고친 뒤에는 **OBS 소스의 URL 도 새로 붙여넣어야**
바뀐 내용이 반영됩니다.
