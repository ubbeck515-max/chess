# OBS 가림 박스 오버레이

방송 화면에서만 닉네임을 덮는 오버레이입니다. 체스닷컴을 전혀 건드리지 않아서
확장 프로그램처럼 계정에 영향을 줄 걱정이 없고, **내 모니터에는 이름이 그대로 보입니다.**
시청자 화면에서만 사라집니다.

| 파일 | 역할 |
| --- | --- |
| `editor.html` | 스크린샷 위에 박스를 그려 프리셋을 만들고, OBS 에 넣을 주소를 뽑는 편집기 |
| `overlay.html` | OBS 브라우저 소스가 읽는 오버레이 본체 |

## 0. 빠르게 시작하기

편집기 상단의 **샘플 프리셋** 을 누르면 `게임·리뷰 / 홈 / 경기 기록·친구창 / 전체 덮기`
네 가지가 들어옵니다. 1920×945 화면에서 잰 값이라 창 크기가 다르면 어긋나니,
캡처를 붙여넣고 위치만 맞추면 금방 끝납니다.

## 1. 박스 그리기

1. 체스닷컴 화면(게임 / 분석·리뷰 / 퍼즐 / 홈·친구창)을 각각 **캡처**해 둡니다.
2. `editor.html` 을 평소 쓰는 브라우저에서 엽니다.
3. 프리셋 탭을 고르고, 해당 화면의 캡처를 창에 **드래그**하거나 `Ctrl+V` 로 붙여넣습니다.
4. 가릴 자리를 마우스로 끌면 박스가 생깁니다. 박스를 끌면 이동, 오른쪽 아래 손잡이로 크기 조절,
   `Delete` 로 삭제입니다.
5. 오른쪽에서 라벨(`Player 1` 같은)과 색을 정할 수 있습니다. 라벨을 비우면 그냥 덮기만 합니다.

좌표는 화면 크기에 대한 **비율(%)** 로 저장되므로, 해상도나 소스 크기가 달라져도 자리가 맞습니다.
다만 브라우저 창 크기를 바꾸면 체스닷컴 레이아웃 자체가 달라지니, **방송할 때 쓰는 창 크기로
캡처**하고 그 크기를 유지하세요.

## 2. OBS 에 넣기

프리셋 하나당 브라우저 소스 하나를 만듭니다.

1. 편집기에서 `overlay.html` 경로를 적습니다. 예: `file:///C:/obs/overlay.html`
2. **현재 프리셋 주소 복사** 를 누릅니다.
3. OBS → 소스 `+` → **브라우저**
4. **로컬 파일 체크는 끈 채로**, URL 칸에 복사한 주소를 붙여넣습니다.
   (로컬 파일로 고르면 뒤에 붙은 설정값을 넣을 수 없습니다.)
5. 너비·높이를 방송 해상도와 같게 맞춥니다. 예: 1920 × 1080
6. 소스를 체스닷컴 캡처 **위쪽**에 둡니다.

프리셋 수만큼 3~5번을 반복하고, 소스 이름을 `가림-게임`, `가림-퍼즐` 처럼 붙여둡니다.

## 3. 화면 전환용 단축키

OBS → 설정 → **단축키** 에서 각 소스의 **표시 / 숨기기** 에 키를 지정합니다.
예를 들어 게임용 `F1`, 분석용 `F2`, 퍼즐용 `F3` 처럼 두면 화면을 옮길 때 키 하나로 바뀝니다.

한 번에 하나만 켜지게 하고 싶다면, 각 오버레이를 **장면(Scene)** 으로 나누고
장면 전환 단축키를 쓰는 편이 더 깔끔합니다.

## 게임이 잡히는 순간

상대를 찾고 나면 중앙에 두 사람 이름이 잠깐 크게 뜹니다. 여기에 맞춰 **매칭 중** 프리셋이 있습니다.
중앙을 넓게 덮는 박스 하나이고, **몇 초 뒤 스스로 사라집니다**(기본 8초).

쓰는 법은 이렇습니다.

1. 이 프리셋으로 브라우저 소스를 하나 만들고, 속성에서 **표시되지 않을 때 소스 종료** 를 켭니다.
   소스를 켤 때마다 페이지가 새로 열려서 시간이 0부터 다시 갑니다.
2. OBS 단축키에서 이 소스의 **표시** 에 키를 하나 겁니다. (숨기기는 걸지 않아도 됩니다)
3. 체스닷컴에서 **게임 시작을 누르기 직전에** 그 키를 누릅니다.
   매칭 화면이 덮이고, 보드가 나올 때쯤 알아서 걷힙니다.

몇 초로 할지는 편집기의 **자동으로 꺼지기(초)** 에서 프리셋마다 정할 수 있습니다.
빠른 매칭이면 6초, 사람이 잘 안 잡히는 시간대면 넉넉히 12초쯤 두면 됩니다.
0 으로 두면 자동으로 꺼지지 않습니다.

## 스크롤하는 화면

홈·경기 기록·친구창은 스크롤하면 이름이 위아래로 움직이는데 박스는 제자리라 어긋납니다.
그래서 이런 화면은 **이름 칸 크기로 잡지 말고 열이나 패널 전체를 덮으세요.**
경기 기록이라면 "플레이어" 열 전체를 세로로 길게, 친구창이라면 목록 영역 전체를 덮는 식입니다.
패널의 위치는 스크롤해도 변하지 않으므로 안쪽 내용이 아무리 움직여도 안전하고,
결과·정확성·날짜 같은 나머지 열은 그대로 보입니다.

게임·분석·퍼즐 화면은 보드가 고정되어 있어 스크롤할 일이 없으니 박스를 정밀하게 잡아도 됩니다.
그래도 불안한 순간을 위해 **전체 덮기** 프리셋을 단축키에 걸어두면, 목록을 뒤질 때
한 키로 화면 전체를 덮었다가 돌아올 수 있습니다.

## 보드 위 이름과 레이팅

보드의 선수 이름과 레이팅은 `이름 (2081)` 처럼 붙어 있고, **레이팅 위치가 이름 길이에 따라
움직입니다.** 그래서 이름만 정확히 덮는 박스는 긴 이름이 삐져나올 수 있습니다.
방송에서 레이팅까지 가려도 괜찮다면 `이름 (레이팅)` 전체를 넉넉히 덮는 편이 안전합니다.
레이팅을 꼭 보여줘야 한다면 박스를 짧게 잡고, 상대가 바뀔 때마다 한 번 확인하세요.

## 설정 백업

편집 내용은 브라우저에 자동 저장됩니다. 다만 `file://` 로 연 페이지는 브라우저 설정에 따라
저장이 막힐 수 있으니, 공들여 잡았다면 **설정 JSON 복사** 로 따로 보관해 두세요.
다른 PC에서는 **설정 JSON 불러오기** 로 그대로 옮길 수 있습니다.

주소 안에 설정이 통째로 들어 있으므로, 박스를 고친 뒤에는 **OBS 소스의 URL 도 새로 붙여넣어야**
바뀐 내용이 반영됩니다.
