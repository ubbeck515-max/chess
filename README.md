# 체스닷컴 닉네임 가리기 (Chrome 확장)

체스닷컴에서 닉네임을 가리고 레이팅은 그대로 보여주는 확장 프로그램입니다.
게임 화면뿐 아니라 **퍼즐**, **분석**, 프로필, 랭킹 목록, 채팅에도 적용됩니다.

## 기능

- **닉네임 가리기** — 닉네임을 `Player 1`, `Player 2` … 로 바꿉니다 (기본 켜짐).
  블러/모자이크가 아니라 텍스트를 바꾸는 방식이라 레이아웃이 깨지지 않고 깔끔합니다.
  같은 사람은 화면 어디에서나 같은 번호를 받습니다.
- **레이팅도 가리기** — 필요할 때만 점수를 `----` 로 가립니다 (기본 꺼짐).
  꺼져 있으면 최고 점수·전술·엔딩 같은 통계 숫자는 전부 그대로 보입니다.
- **마우스 올리면 원래대로** — 가려진 부분에 커서를 올리면 원래 값이 보입니다 (기본 켜짐).
- 툴팁(`title`/`aria-label`)과 브라우저 탭 제목(`alice vs bob`)으로 이름이 새는 것도 막습니다.

## 설치

1. Chrome 주소창에 `chrome://extensions` 입력
2. 우측 상단 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드** 클릭
4. 이 저장소 폴더를 선택

툴바 아이콘을 눌러 옵션을 켜고 끌 수 있고, 변경은 열려 있는 탭에 바로 반영됩니다.

## 구조

| 파일 | 역할 |
| --- | --- |
| `manifest.json` | MV3 매니페스트 |
| `content.js` | 닉네임·레이팅 텍스트 치환, 툴팁/탭 제목 정리, DOM 변화 감시 |
| `mask.css` | 바뀐 텍스트 스타일, 로딩 순간 깜빡임 방지 |
| `popup.html` / `popup.js` | 토글 UI, `chrome.storage.sync`에 저장 |

## 동작 방식 메모

체스닷컴은 닉네임과 레이팅을 한 컨테이너에 같이 넣는 경우가 많습니다.
그래서 컨테이너째 가리면 점수까지 같이 사라집니다.
`content.js`는 **안에 다른 닉네임/레이팅 요소를 품고 있지 않은 잎(leaf) 요소에만** 마스킹을 걸고,
요소 안의 텍스트 노드만 바꿔서 국기·아이콘 같은 자식 요소는 건드리지 않습니다.

클래스 이름은 화면마다 다르고 수시로 바뀌므로 `[class*="username"]` 같은 부분 일치 선택자를 씁니다.
안 가려지는 화면이 보이면 `content.js`의 `NAME_SELECTOR` / `RATING_SELECTOR` 목록에 추가하면 됩니다.

### 클래스 이름으로 못 찾는 자리

게임 리뷰 패널의 선수 이름이나 왼쪽 아래 내 계정처럼, 클래스 이름에 `username`이 없어
선택자로는 못 잡는 자리가 있습니다. 그래서 `content.js`는

1. 프로필 링크(`/member/<닉네임>`)와 이미 가린 요소에서 실제 닉네임을 배우고,
2. 배운 닉네임을 페이지의 텍스트에서 직접 찾아 같은 `Player N` 으로 바꿉니다.

덕분에 새 이름을 하나 배우면 이미 그려진 화면까지 함께 정리됩니다.
