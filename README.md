# 체스닷컴 방송용 닉네임 가리기

방송에서 상대와 내 닉네임을 가리기 위한 도구 모음입니다.

| 폴더 | 내용 | 상태 |
| --- | --- | --- |
| [`obs-panel-layout.md`](obs-panel-layout.md) | 보드·기보·메모·채팅을 카드로 나눈 패널형 화면 만들기 | 화면 구성 |
| [`obs-layout.md`](obs-layout.md) | 보드만 크게 쓰는 방송 화면 배치표와 정렬 가이드 이미지 | 화면 구성 |
| [`obs-basic.md`](obs-basic.md) | OBS 기본 소스(색상·텍스트)만으로 가리는 방법 | **가장 간단** |
| [`obs-overlay/`](obs-overlay/) | 박스가 많고 화면별 전환이 필요할 때 쓰는 오버레이 | 선택 |
| [`extension/`](extension/) | 체스닷컴 페이지를 직접 고치는 크롬 확장 | 사용 중단 (아래 참고) |

## 왜 OBS 쪽인가

체스닷컴 지원팀에서 **페이지를 고치는 방식은 안 된다**는 답변을 받았습니다.
닉네임을 다른 글자로 바꾸는 것도 페이지 변조에 해당합니다.
브라우저 확장뿐 아니라 사용자 스크립트, OBS 브라우저 소스의 Custom CSS 주입도
모두 같은 범주이므로 쓰지 않습니다.

`obs-overlay/` 는 다릅니다. 내 PC가 만든 **영상 출력 위에** 사각형을 그릴 뿐이라
브라우저에도, 체스닷컴 서버에도 아무 신호가 가지 않습니다.
체스닷컴 입장에서는 방송에 검은 사각형이 하나 떠 있는 것과 구별되지 않습니다.

## 어느 쪽을 쓸까

박스가 두세 개면 [`obs-basic.md`](obs-basic.md) 가 낫습니다. 설치할 파일이 없고,
글자를 메모장으로 고쳐 저장하면 방송에 바로 반영됩니다.

박스가 여러 개이고 게임·분석·퍼즐·목록 화면을 자주 오간다면 `obs-overlay/` 가 낫습니다.
OBS 소스를 열 개씩 만들지 않아도 되고, 화면별 프리셋을 단축키로 전환할 수 있습니다.

## 오버레이로 시작하기

[`obs-overlay/README.md`](obs-overlay/README.md) 를 따라가세요. 요약하면

1. `editor.html` 을 열고 **샘플 프리셋** 을 불러옵니다
2. 방송에 쓸 창 크기로 체스닷컴을 캡처해 편집기에 붙여넣고, 박스를 자기 화면에 맞춰 옮깁니다
3. 나온 주소를 OBS 브라우저 소스의 URL 칸에 넣습니다
4. 화면별 프리셋을 OBS 단축키로 전환합니다

## extension 폴더에 대해

지원팀 답변 전에 만든 크롬 확장입니다. **체스닷컴에서는 쓰지 마세요.**
설치해 두셨다면 `chrome://extensions` 에서 제거하시면 되고, 새로고침하면 페이지는 원래대로 돌아갑니다.

지우지 않고 남겨둔 이유는 기록 때문입니다. 여기에는 체스닷컴 화면 어디에 닉네임이 나타나는지
(보드 태그라인, 게임 리뷰 패널, 친구 목록, 경기 기록, 사이드바 내 계정) 정리된 선택자 목록이 있어서,
오버레이 박스를 어디에 둘지 정할 때 참고가 됩니다.
